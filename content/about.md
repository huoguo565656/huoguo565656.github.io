## 这个站是什么

一个**用 Agent 做小工具**的记录本。

不是教程，是施工日志：想到什么、怎么做的、哪里卡住了。特点是小而具体——
不追大而全的框架，先把一个念头做成能跑的东西，跑起来了再想下一步。

## 为什么记这些

因为很多东西，我以前觉得「以我的水平是做不出来的」。

现在借着 Agent 一件件做出来了，才发现**真正难的不是写代码，是想清楚要什么**——
要什么效果、边界在哪、什么样算做完了。这些想清楚了，剩下的多半只是时间问题。

所以这个站也是个积累：把做出来的东西记下来，顺便给自己攒点底气。
以后会继续往那些**以前不敢想**的方向试。

## 都记些什么

| 类型 | 写什么 |
|---|---|
| **小巧思** | 想到什么、为什么觉得可行、边界在哪 |
| **实现过程** | 提示词、脚本、代码，能直接抄的 |
| **踩坑记录** | 尤其是那种不记下来下次还会踩的 |
| **半成品** | 没做完的也记：卡在哪、还差什么、打算怎么走 |

## 几条约定

| 约定 | 说明 |
|---|---|
| **能跑才算数** | 贴出来的代码都是实际跑过的 |
| **没验证就标明** | 写成「待验证」，不包装成结论 |
| **给可复现的步骤** | 而不是「大概这样就行」 |
| **写清失败** | 走不通的路也值得记，省得再走一遍 |
