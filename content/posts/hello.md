这个站用来放**用 Agent 做小工具**的记录，不是资讯搬运站。

基本上每一篇都是一个「原来还能这么干」的念头，然后把它做成能跑的东西。

## 写哪几类

- **小巧思**：想到什么、为什么觉得可行、边界在哪
- **实现过程**：提示词、脚本、代码，能直接抄的
- **踩坑记录**：尤其是那种不写下来下次还会踩的
- **半成品**：没做完的也记——卡在哪、还差什么、打算怎么走

## 为什么要开这个站

因为很多东西我以前觉得「以我的水平是做不出来的」。

真做出来之后发现，**难的不是写代码，是想清楚要什么**：要什么效果、边界在哪、
什么样算做完了。这些想明白了，剩下的大多是时间问题。

所以这里也算是个积累。以后会继续往那些**以前不敢想**的方向试。

## 几条自我约束

1. **能跑才算数**：贴出来的代码都是实际跑过的。
2. **没验证的就标「待验证」**，不包装成结论。
3. **不写「我觉得应该没问题」**。要么跑过，要么说明这是推测。
4. **写清失败**：走不通的路也值得记，省得再走一遍。
5. **给可复现的步骤**，而不是「大概这样就行」。

## 怎么组织的

文章按**技术栈**（`Hugo`、`Python`、`WSL2`…）和**做的事**（`建站`、`自动化`、`微信推送`…）
两个维度打标签，归档页按时间排。

写作模板和字段约定见仓库里的 `docs/写作规范.md`，新文章用：

```bash
./scripts/new-post.sh "文章标题" --slug my-post
```

会按模板生成带好 frontmatter 的 Markdown 文件。

## 关于更新

这个站的搭建、发布、搜索、站内编辑这些事情，本身就是「用 Agent 做小工具」的一部分，
所以过程会陆续写成文章。有些功能以前觉得做不出来，现在就在眼前跑着，挺好。
